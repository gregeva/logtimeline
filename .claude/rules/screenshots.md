# Documentation screenshots

`docs/process/screenshots.md` is the rule; these are the parts that matter most:

- Images under `images/screenshots/` are generated by
  `build/capture-screenshots.pl` from `build/screenshots.yaml`, never edited by
  hand and never captured from a terminal window. A change is a change to the
  entry, then `--manifest build/screenshots.yaml --only NAME`.
- A new screenshot is a new manifest entry with a comment saying what it is for
  and anything measured to build it (the columns a crop cuts).
- Rows are chosen by section, columns by position at the entry's width; a part
  printed side by side (the summary's file list, one of several histograms) is
  isolated by its columns, since hiding its neighbour does not move it.
- Look at every image written before it is committed, and check any the tool
  marks as showing messages or the file list for sensitive content: the
  repository is public.

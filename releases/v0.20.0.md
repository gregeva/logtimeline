# Release v0.20.0 - Notices Surface & TUI

## What's New

- Add `-mt`/`--message-truncation` to choose where a long message is cut in the messages table. See docs/usage.md (#564)
- Report the peak memory used on Windows on every run, with or without `-mem`/`--memory-usage`. (#146)
- Show the run's notices by category in a panel before the timeline, every one listed by `-V notices`. See docs/usage.md (#412)
- Ask before reading whether to continue when the given options raise notices. See docs/usage.md (#412)

## Bug Fixes

- Refuse a negative `-n`/`--top-messages` or `-gc`/`--group-ceiling` as a usage error (#726)
- Start `ltl` from source with the `perl` first on `PATH`, on hosts with or without Homebrew (#750)
- Render each duration at the precision the log writes it, whatever unit `-du`/`--duration-unit` reads it in, user-defined time and byte metrics included (#759)
- Write CSV duration and percentile columns with the decimals the log's durations carry under the default `-cp`/`--csv-precision` (#759)
- Note a duration bound finer than the precision the log's durations carry, on every log format (#759)
- Clamp `-tp`/`--timestamp-precision` to the finer unit a timestamp's partial group of fractional digits reaches (#759)

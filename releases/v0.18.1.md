# Release v0.18.1 - Packaged-binary fix for the YAML aggregate export

## Bug Fixes

- `-o` no longer fails on the downloadable binaries. Every run that wrote the YAML aggregate export died before writing it, on all platforms, reporting a missing module that was present on the machine and could not be supplied by installing it; the STATS and MESSAGES CSVs were written and the YAML was not. Introduced in v0.18.0, the first release to write the export. (#541)

# Release v0.18.3

## What's New

- New: `-d <name>` / `--discard <name>` removes a named part of the line so that it takes no part in the run: it is gone from the message, from every count and from every statistic, as if it had never been written, so that messages differing only in that part become one. Name the thread, session, user or object, whose value is cleared everywhere it was counted; `uuid`, `ipv4`, `ipv6` or `ip`, removed wherever they sit in the message; the query string; a metric (`duration`, `bytes`, `count`, or one of your own), which is then not read at all; or any key written in the line, such as a signature in a download URL, which goes with its value and one separator. Repeat the option or give a comma-separated list. A name given to both `-x` and `-d`, or to both `-m` and `-d`, is discarded, and `ltl` says so. `-x` now accepts a comma-separated list too. (#567)

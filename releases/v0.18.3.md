# Release v0.18.3 - Test Harness Bug Fixes & Discard Feature

## What's New

- Add `-d`/`--discard <name>` to remove a named value from the message and from all counts and statistics (#567)
- Make `-x`/`--expose` accept a comma-separated list (#567)

## Performance

Access logs and ScriptLog run about 1.6% slower than v0.18.2; Thingworx
application logs are unchanged. The cost is not the new options doing work — a
run that names nothing skips them — but the extra branches they add to the loop
that reads every line, which the formats spending most of their time in that
loop feel most. It is accepted for this release. Full comparison in
`tests/baseline/results/comparison-v0.18.2-vs-v0.18.3.md`.

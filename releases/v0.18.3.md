# Release v0.18.3 - Test Harness Bug Fixes & Discard Feature

## What's New

- Add `-d`/`--discard <name>` to remove a named value from the message and from all counts and statistics (#567)
- Make `-x`/`--expose` accept a comma-separated list (#567)

## Performance

Access logs and ScriptLog run about 1.6% slower than v0.18.2, measured with both
versions run on one machine in one sitting; Thingworx application logs are
unchanged.

A run that names nothing to discard or expose does not execute any of the new
work — profiling confirms both versions run the same steps the same number of
times per line. The cost is that the code reading each line has more branches to
carry, whether or not a run uses them, and it grew gradually as the feature was
built rather than arriving with one part of it. A format pays in proportion to
how much of its time is spent reading and interpreting lines, which is why
access logs feel it and Thingworx application logs do not.

Accepted for this release; the shape of that per-line code is being looked at
separately. Full comparison in
`tests/baseline/results/comparison-v0.18.2-vs-v0.18.3.md`.

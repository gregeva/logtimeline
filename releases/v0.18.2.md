# Release v0.18.2

## What's New

- Deprecated: the Integration Runtime and Connection Server log formats no longer read a duration from "N milliseconds" in the message, and the number now stays in the message instead of becoming `?`; to keep reading that value, add the user-defined metric `-udm "elapsed:ms::/ (\d+) milliseconds/"`. (#576)

## Bug Fixes

- On access logs that carry a thread name, a thread written as `-` is now treated as absent: the message no longer carries a `[-]` segment. (#565)
- A counting user-defined metric (`count`, `distinct`, `ratio`, `rate`, `drate`) on a URL query-string parameter now counts that parameter's value: the value ends at `&` or `?` instead of running on through the rest of the query string. (#574)

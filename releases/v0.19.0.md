# Release v0.19.0

## What's New

- Leave the MESSAGES CSV `duration_nice` cell empty under `-od`/`--omit-durations` (#273)
- Add an `impact` topic to `-ex`/`--explain` (#616)
- Write an empty `ltl-index.csv` mean cell when there is no data (#616)
- Add `-tp`/`--timestamp-precision` to set the timestamp precision, minute to nanosecond, never finer than the log carries. See docs/usage.md (#525)
- Deprecate `-s`/`--seconds` and `-ms`/`--milliseconds`: use `-tp`/`--timestamp-precision` and a unit on `-bs`/`--bucket-size` (#525)
- Accept millisecond, microsecond and nanosecond spelled out wherever a time unit is taken (#525)
- Round each timestamp once, so the run summary, YAML export and `ltl-index.csv` show the same instant (#525)
- Write `ltl-index.csv` timestamps at the run's precision, stated on every row (#525)
- Deprecate `time` as a metric name on `-hm`/`--heatmap`, `-hg`/`--histogram` and `-so`/`--sort-on`: use `duration` (#613)
- Deprecate `size` on `-so`/`--sort-on`: use `bytes` (#613)
- Deprecate `std_dev` on `-so`/`--sort-on`: use `stddev` (#613)
- Match built-in metric, field and identifier names in any case on every option (#613)
- Match a metric's key such as `durationMS` as written on `-x`/`--expose` and `-d`/`--discard`; see docs/usage.md (#613)
- Print a notice when `-d`/`--discard` removes a key a metric reads, switching that metric off (#613)
- Append the full object with `-x`/`--expose object` (#613)
- Remove a masked key whole with `-d`/`--discard`, leaving no `?&` or doubled space (#613)
- Apply `-d`/`--discard` identifier removals in the order `-m`/`--mask` applies them, whatever order they are typed (#613)
- Show each number one way on every surface, fitted to its column, never cut, never below the log's own unit (#617)
- Show counts of up to five digits in full on the legend, charts and timeline columns (#617)
- Write a user-defined rate's CSV cells at one decimal, as the built-in rates are written (#617)

- Accept a unit on count, byte and duration options, such as `-dmin`/`--duration-min 200us` or `-gc`/`--group-ceiling 2M`; see docs/usage.md (#605)
- Add a `units` topic to `-?`/`--help` (#605)
- Refuse a negative value on the numeric filter and highlight options, such as `-dmin`/`--duration-min` (#605)
- Print a note when a duration bound is finer than the unit the log records durations in (#605)
- Write the numeric exclusion count in the YAML export on every run (#605)
- Print the log-format ambiguity note once per run, naming every file it concerns (#605)
- Read a CSV file's dates day first when its own rows are real dates only that way; see docs/usage.md (#615)
- Read a CSV timestamp's fraction to nine digits, as written under `-tp`/`--timestamp-precision ns` (#615)
- Show a CSV file's timestamps no finer than they carry, with the note `-tp`/`--timestamp-precision` gives a log file (#615)
- Skip session, user and `ltl-index.csv` capture no output reads: `-hi`/`--hide session`, `--hide user` and `-ni`/`--no-index` runs read faster (#620)
- Deprecate the run index, `ltl-index.csv`, for removal in a later release (#708)
- Stop reading and writing `ltl-index.csv` by default; `-idx`/`--index` turns it on (#708)
- Stop with an error naming each file argument that selects no file, when other arguments select files (#614)
- Read the word after an option whose value is optional, such as `-hg`/`--histogram`, as a file when the option does not take it; see docs/usage.md (#614)
- Refuse a `-hg`/`--histogram` or `-V`/`--verbose` list that names an unknown metric or section (#614)
- Accept every metric statistic on `-so`/`--sort-on` as `<metric>_<statistic>`, such as `bytes_avg`; see docs/usage.md (#614)
- Refuse `-so`/`--sort-on` names that mix two metrics, such as `duration_bytes` (#614)
- Deprecate `total` and `count_total` on `-so`/`--sort-on`: use `occurrences` and `count_occurrences` (#614)
- Explain the statistic behind any `-so`/`--sort-on` name with `-ex`/`--explain`, such as `duration_p95` (#614)
- Name every `-?`/`--help` topic, `profile` included, in the help (#614)
- Point an unknown `-pr`/`--profile` mode to `--help profile`, and claim no `day-alt` mode (#614)
- Rename `duration_std_dev`, `err-rate_<unit>` and `msg-rate_<unit>` in CSV output, and `std_dev` in the YAML export, to `duration_stddev`, `err_rate_<unit>`, `msg_rate_<unit>` and `stddev` (#618)
- Write a user-defined `ratio` metric's CSV cells at the `-cp`/`--csv-precision` decimals, three by default (#618)
- Apply `-cp`/`--csv-precision` to each function column of a user-defined metric typed with two functions, such as `c:mean` (#618)

## Bug Fixes

- Hide the heatmap with `-hi`/`--hide heatmap`, apart from the statistics column `--hide stats` hides (#692)
- Show the latency statistics beside the heatmap with `-sh`/`--show stats` (#692)
- Print the heatmap's scale only when the heatmap column is shown (#692)
- Accept `sessions` and `users` on `-hi`/`--hide` and `-sh`/`--show`, as the column headings read (#692)
- Fix `-udm`/`--user-defined-metrics` byte units resolving differently between runs: `KB` always means 1000 bytes, and the column carries the canonical unit (#608)
- Show byte values in SI units by default, or in a log format's declared notation; `-bn`/`--byte-notation iec` shows KiB and MiB. See docs/usage.md (#608)
- Set CSV duration decimals to the source unit's resolution under `-du`/`--duration-unit ns` and `-du us`; `-cp`/`--csv-precision` gives more. See docs/usage.md (#608)
- Read Java GC heap sizes in powers of 1024, as the JVM writes them (#609)
- Leave a time bucket's total empty when no line carried that metric, on the timeline and in CSV and YAML output; see docs/usage.md (#616)
- Compute impact from each message's reported mean duration, ranking a message without one by its occurrences; see `-ex`/`--explain impact` (#616)
- Round the MESSAGES CSV `bytes_mean` through `-cp`/`--csv-precision` (#616)
- Count zero-byte responses in the `ltl-index.csv` bytes columns (#616)
- Pre-seed the bytes heatmap's range from `ltl-index.csv` (#616)
- Report the same peak memory in the run summary and the YAML export (#616)
- Group messages with `-g`/`--group-similar` only within the same log level or HTTP status, in every pass; see docs/usage.md (#619)
- Stop runtime warnings on stderr when grouping messages with `-g`/`--group-similar` under `-mdm`/`--message-stats-data-model bin` (#619)
- Stop `-du`/`--duration-unit` converting durations a second time on access logs that write a unit beside each duration (#605)
- Lower peak memory of statistics on runs whose messages or time buckets hold millions of values (#680)
- Describe `delta` as keeping and `idelta` as dropping negative differences in the `-udm`/`--user-defined-metrics` help (#698)
- Skip a log line or CSV row whose date cannot exist, with one note per format giving the count (#611)
- Read `-st`/`--start` and `-et`/`--end` timestamps written with a `T` separator; see docs/usage.md (#611)
- Refuse an `-st`/`--start` or `-et`/`--end` value that is not a timestamp, with a usage error naming the accepted forms (#611)
- Read the quoted timestamps `-o`/`--output-csv` writes, CSV timestamps without seconds, and epoch numbers in the unit their digit count states; see docs/usage.md (#611)
- Switch a log's day/month date order only when enough recent lines are dated the other way round (#704)
- Complete a `-hm`/`--heatmap` run on a user-defined metric whose every value is zero (#678)
- Draw an empty heatmap for a user-defined metric that captured no value, instead of ending the run (#713)
- Keep each `-udm`/`--user-defined-metrics` metric's colour when an earlier metric captured nothing (#678)
- Draw a `-hg`/`--histogram` of a user-defined metric under `-h`/`--highlight` when no highlighted line carries that metric (#719)
- Let `-dbg`/`--dark-background` override `-lbg`/`--light-background` on every run, with or without a heatmap (#665)
- Query the terminal for its background only when a heatmap will be drawn (#665)

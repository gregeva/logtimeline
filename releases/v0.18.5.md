# Release v0.18.5 - UDM RegEx Parsing Fixes

## Bug Fixes

- Apply user-defined metric patterns only to lines that match a log format, never to continuation lines of multi-line entries (#637)
- Skip and report user-defined metric captures that are not numbers; see `docs/usage.md` (#638)
- Read CSV rows without a usable timestamp as unmatched lines, silently (#640)
- Report a user-defined metric missing from CSV headers once per run, without file names (#640)

# Release v0.18.4 - Automated Screenshot Capture

## What's New

- Add `-hi`/`--hide` and `-sh`/`--show` to hide or restore output sections and timeline columns, user-defined metric columns included; see `docs/usage.md` (#597)
- Add `-V section-layout`, reporting the row each output section starts on and how many rows it prints (#597)
- Separate output sections by exactly one blank row (#597)
- Print the unhandled date/time format warning on standard error (#597)
- Leave terminal-size, background, progress and `-V` options off the echoed command line and the aggregate export's option record (#598)

## Performance

The full benchmark ran against v0.18.3 on one machine: total run time is 2.3% lower and
peak memory 0.8% higher overall, with no regression. Per-case results are in
`tests/baseline/results/comparison-v0.18.3-vs-v0.18.4.md`.
